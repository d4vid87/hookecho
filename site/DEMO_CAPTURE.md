# HookEcho media capture · October 4, 2026

The site and GitHub gallery were recaptured from the current HookEcho UI. Desktop and web archive media use real KTLX Level 2 scans and timestamped warning polygons from May 20, 2013, near Moore, Oklahoma. Live storm attributes and national MRMS media were captured on October 4, 2026. The Android recording came from the signed `feature/mobile-refresh-media` preview APK on a Galaxy S24 Ultra; its Signal Deck and Quiet Shelf use the same app code merged into main.

The web source scenes were `https://app.hookecho.io/#goto=KTLX,-97.36,35.40,9.9,2013-05-20T20:15:00Z` and `https://app.hookecho.io/#goto=KBMX,-86.6,32.4,6.8,thr:16,bm:dark`. `scripts/shots/capture-web-showcase.cjs` captured real browser frames. `scripts/shots/encode-web-showcase.sh` encoded the MP4, WebP, GIF, and README assets without interpolating scans. `scripts/shots/shoot.sh` captured the desktop archive and live gallery scenes on Xvfb. Android frames came from `adb exec-out screencap` and were encoded by `scripts/shots/encode-android-showcase.sh`; the personal status bar was cropped before publishing. The Android capture preserved the phone's app data and saved places.

The animated media is archival or recorded. It is not a live forecast. The homepage identifies the archive date and the capture date beside each clip. The live October 4 captures are frozen examples of the current interface and weather at recording time.
