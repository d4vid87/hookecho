# Public-data alternatives

Audited October 14, 2026. The user accepted public-data substitutes for proprietary device telemetry, chaser video and international feeds. This changes the target provider scope; it does not make the substitutes identical or complete. No private RadarOmega service, source code, account or key is reused. Official documentation, source integration and a live metadata response are separate evidence levels.

## Focused refinements implemented

- ECCC frame discovery now requests layer-filtered GetCapabilities, parses the requested layer's time dimension and intersects the requested window before limiting frames. The existing catalog refresh clock is sixty seconds. Responses are bounded to 256 KiB with the feed timeout. Empty, malformed or failed availability returns no guessed frames. The existing renderer suppresses timed imagery when no frame is selected. DWD's existing cadence grid is unchanged.
- The imagery time bar and map status name the actual map source; “Link imagery panes” applies to both satellite and radar composites.
- Caltrans metadata expires after fifteen minutes in a stationary view. A changed view still refreshes immediately, and a failed attempt does not trigger an every-frame retry. This addresses catalog status/media URL freshness, not continuous validation of a stream already open.
- The shared map picker's Weather group includes **Australian radar ↗ BOM official viewer**, explicitly opening the external site. No Australian radar data is embedded.

Validation: the stationary-camera expiry boundary/cooldown test passed (1/1). Three focused ECCC availability tests passed (3/3), covering expired/future requests, interval intersection before limiting, six-minute boundaries, wrong layers and malformed/empty metadata. Commands: `cargo test -p wxdata --lib catalog_expiry_tests --offline` and `cargo test -p hookecho --lib eccc_availability_tests --offline`. No native/browser media playback or final UI validation is claimed by these unit tests.

Completion still requires integrated UI checks for sensor stale/error recovery at other locations, longer-session stream recovery, ECCC continuous animation, additional DWD products/elevations and interactive playback, and the remaining browser proxy paths. The native checks establish the NWS parsing chain and one DWD REF render; later browser checks establish one NWS sensor presentation and one Caltrans still/live stream interaction. They do not satisfy the remaining UI/media gates.
